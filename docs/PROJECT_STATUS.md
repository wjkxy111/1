# 项目成熟度评估

## 当前等级：工程原型 / 台架联调前（约 55%）

已完成并通过编译/主机测试的部分：

- F28P65x Flash 工程、SysConfig 外设配置和 DriverLib HAL。
- 上电默认失能、显式启动、急停和故障锁存。
- 双编码器速度快照、双电机 PID、8 路循迹与丢线停车。
- K230 协议严格解析、帧超时、置信度门限、STOP/障碍物停车和限速融合。
- 控制算法与 K230 解析器的主机测试。

尚未完成、因此不能称为实车成熟版的部分：

- 未在你的具体电机驱动、编码器和灰度模块上完成电气验证。
- 编码器 CPR、正反号、轮径、轮距和 PID 尚未系统辨识/标定。
- K230 侧模型、摄像头标定、数据集、训练和部署工程不在本目录。
- 没有电流/电压采样、欠压、堵转、过流、驱动器故障脚和硬件急停回路。
- 没有独立看门狗、启动自检、持久故障记录、功能安全分析和 EMC 验证。
- 尚未进行长时间路测、边界工况注入、CAN/车载诊断或量产 Bootloader 集成。

## 建议验收顺序

1. 不接电机电源，示波器验证 PWM/DIR/EN 和急停时序。
2. 轮胎离地，低占空比验证左右方向与编码器符号。
3. 固定 10 ms 周期采集阶跃响应，辨识并重调速度环。
4. 低速本地灰度循迹，不启用 K230；验证丢线 1.5 s 后停车。
5. UART 回放 K230 帧，验证过期帧、低置信度、STOP 和 300 mm 障碍策略。
6. 最后接入真实 K230 模型，并记录帧龄、置信度、控制输出和停车原因。
